# Cyber Threat Pipeline

## Overview

A Linux-based cybersecurity data pipeline that collects, processes, and analyzes the CISA Known Exploited Vulnerabilities (KEV) Catalog using Google Cloud services.

The goal of this project is to demonstrate Linux administration, Bash scripting, cloud data engineering, SQL analysis, and cybersecurity risk reporting.

## Technologies Used

### Operating System
- Debian Linux

### Cloud
- Google Cloud Compute Engine
- Google Cloud Storage
- BigQuery
- Looker Studio

### Programming / Tools
- Bash scripting
- SQL
- Git/GitHub
- jq JSON processing

---

## Current Features

- Debian Linux cloud environment
- GitHub version control
- Automated vulnerability data download script
- Logging system
- CISA KEV dataset collection
